# Meeting notes and follow-through

Work from the provided notes or transcript. Identify the meeting's date and
participants only when recorded. Treat suggestions, decisions, and unresolved
questions separately; silence or a tentative proposal is not agreement.

Summarize the outcome in plain language, then extract actions with the task,
owner, due date, and dependency when available. Mark an unassigned owner or
missing deadline as unspecified instead of guessing. Preserve material objections
and uncertainty. Cite transcript timestamps or note sections for disputed or
consequential decisions when those references exist.

Keep the summary proportional to the meeting. Reconcile repeated or conflicting
notes without silently choosing a version. Call out an incomplete transcript
when it limits the conclusions. Produce a follow-up message if requested.

Recording actions in the summary does not create tasks, send messages, or schedule
meetings. Use available task or calendar tools only for actions the user requested,
and report which records were actually created versus merely proposed.
