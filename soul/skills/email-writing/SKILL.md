# Workplace email

Use the supplied thread and the user's desired outcome to identify the recipient,
relationship, and next action. Preserve names, dates, prices, and commitments from
the source. When a missing fact changes the message's meaning, ask for it or leave
a clearly marked placeholder; do not invent an agreement or previous discussion.

For a new email, include a useful subject and put the request or main point near
the beginning. Match the recipient and the user's voice. For a reply, address the
open questions and avoid repeating the entire thread. For a follow-up, state what
is needed and any real deadline without implying the recipient agreed to it.

Deliver one ready-to-use draft unless alternatives are requested. If revising,
preserve the user's position rather than softening it into a different decision.
Check that recipients, attachments, and referenced links are actually available.
Drafting alone does not authorize sending. Use a connected mail tool only when
the user has requested that action, and claim delivery only after a successful
tool result. Otherwise leave the draft in chat or the requested local file.
