# Presentations

Start from the audience, presentation length, and decision or takeaway. Use the
supplied material and any required company template. Select a feasible slide
count for the available speaking time rather than creating a fixed-size deck.

Build a narrative from the problem or context to the evidence and requested
action. Give each slide a message-led title, a small amount of supporting content,
and a proposed visual only when it clarifies the point. Use speaker notes for
detail that would overcrowd the slide. Preserve source references for figures.

Mark missing evidence or illustrative numbers explicitly. Do not fabricate charts,
customer quotes, logos, or performance metrics. For an existing deck, keep its
approved message and identify substantive changes when rewriting.

Return an outline and notes when no slide-generation tool is available. If the
user requested a deck file and a suitable tool is present, create it, inspect the
rendered slides or available preview, and check that text, charts, and citations
are readable. Report the actual artifact produced rather than calling an outline
a finished PowerPoint.
