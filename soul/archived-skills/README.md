do not load them. They cover HANNI-specific infrastructure, GPU benchmarking,
MCP server development, and development experiments. Their original files and
supporting resources are preserved here.

To restore a skill, move its entire folder back into `soul/skills`. The next
task and Skills panel refresh will discover it; no service restart is needed.

The active collection covers research, cited answers, knowledge management,
recurring work, GitHub, code inspection and review, QA, debugging, code cleanup,
