# Campaign 5: adaptive model intelligence

Baseline is the current checkout, including the uncommitted, verified Campaign
4 workflow repairs. Preserve those files, all owner configuration, memories,
workflow databases, default model and unrelated files. The common campaign
rules require synthetic inputs, isolated storage, actual evidence, independent
verification, prospective annotations, checkpoint provenance and honest limits.
As in Campaigns 1–4, no separate common-instructions document has been found.
These rules carry forward the explicit campaign requirements and previously
documented validation protocol; no missing document is claimed to have been read.

Two actual engineering agents own intelligence boundary tests and the live
benchmark harness. An independent actual verifier authors and seals 100 private
final tasks before repairs, with ten in each requested family. The manager does
not inspect private inputs, answers or author code. Final evaluation requires
an explicit whole-implementation/input freeze and is once-only; final answers
must not guide tuning. Separate exposed development failures may guide general
architectural repairs after independent reproduction.

Development seals at least 200 tasks before observing responses, twenty per
family: simple commands, tool selection, planning, coding, analytical reasoning,
long-context retrieval, structured output, memory-assisted questions, workflow
reasoning and complex multi-step analysis. Inputs and deterministic reference
oracles remain separate. References come from synthetic facts, algorithms,
schema/graph checks and restricted executable tests, never teacher-generated
model answers. Model agreement is not verification. Dynamic tasks and memories
never authorize side effects.

Discover every configured endpoint through original protected transports.
Record configured versus observed model, model/backend identity, health,
reported/configured versus independently verified context, actual resources,
privacy categories and native eligibility. A model label or parameter count
does not establish identity, capability, context or quality. Do not start,
replace or stop owner model services, weaken authentication, edit deployment
configuration, or bypass original memory/privacy admission. Read-only owner
deployment/context files may be copied into campaign-owned isolated registries;
original bytes must remain unchanged. Prompts sent to nodes are synthetic and
must fit configured data-sharing restrictions.

Compare the resident 4B, each available individual worker, Strata, native
adaptive placement and selective native collaboration on the same tasks and
prospective settings. Use temperature zero and top_p one; default output budget
256 tokens, with prospectively justified family budgets up to 512. Preserve
native conservative context accounting and original format/transport limits.
Individual modes are pinned without fallback. Adaptive policies use only
development measurements bound to current identities. Forced bounded paired
development collaboration may establish evidence; final selective mode uses
the original policy and only development comparisons. Routine work stays
single-model. Final results never become selection or collaboration profiles.

All inference must produce actual local/cluster model responses through the
original supported APIs. Retain synthetic request-body hashes, response bytes,
observed model, finish reason, usage, latency and authoritative telemetry.
Never substitute canned responses for unavailable endpoints. Refused or
unavailable requests remain blocked/not executed, with semantic metrics null
rather than a fabricated pass or zero-token model answer. Controlled HTTP or
adapter fixtures are a separate implementation fault suite, not live results.
Capability bootstrap/context probes require explicit real implementation and
resource admission; configured capacity is not a near-limit retrieval proof.

Tests use isolated model-routing, compute, lab and memory databases. Coding
outputs run only in restricted, bounded, campaign-owned child processes with
independent assertions; no generated shell commands or imports execute against
the owner's computer. Endpoint-failure tests use disposable adapters; never
disconnect, reboot or kill an owner endpoint to create a fault.

Measure task and structured-output success, latency P50/P95, prompt/generated
tokens when actually reported, resource observations and orchestration overhead.
Publish denominators per family/model/mode, blocked tasks, unmeasured fields,
timeouts and disagreement handling. Compare paired task outcomes; report
uncertainty and practical latency/token costs. Adaptive or collaboration benefit
requires independent real-response confirmation over the applicable baseline;
mock wins, historical scores, agreement and unavailable baselines cannot prove
it. If benefit is absent or unmeasurable, preserve the configured baseline and
explain why. No automatic main-model replacement follows from this campaign.

Archive exact original source before repairs. Record each implementation and
independent verification cycle, commands, source/corpus hashes, outcomes and
remaining blockers. Before final execution pin all production code, helpers,
configuration and prospective inputs. Preserve raw failed runs and provenance
corrections. Derived public reports are outside the freeze so they can publish
without changing tested code or sealed inputs.
