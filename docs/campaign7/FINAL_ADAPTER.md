# Independent final adapter scope

The sealed inputs and oracles are separate private files. The public input-only
executor imports no oracle. The exclusive whole-run claim precedes any execution;
source hashes are checked before each case. Grading begins only after the complete
raw run closes, and missing fields do not count as measured nulls. No preview,
case filter, final retry or changed oracle is supported.

Voice transcript decisions use the original classifiers, and pump/state controls
use the original pipeline, managed pump and interaction classes. A controlled
decoder response tests the STT protocol, not transcription accuracy. The declared
`model_calls` field counts controlled decoder calls only. All actual ASR and
physical audio counts remain separate. Stop/capture controls never open a real
audio backend. Per-case worker threads terminate before the next case.

Screen cases call the original awareness projection, registry, fixed HTTP route,
native image rejection and pure eligibility guards through the worker's input-only
audit. Missing capture, context, expiry and sensitivity mechanisms remain absent.
Saved retention is parsed by the original configuration validator; out-of-range
settings remain rejected rather than silently clamped. Model capability checks
are controlled eligibility contracts, not available physical-model verification.

For the shared screen audit, request `capabilities` are task requirements and
an optional string `model` uses the original model_spec catalog lookup before the
controlled eligibility check; catalog presence does not establish a live endpoint.
A null or absent model does not perform that lookup. `profile` labels do not replace the original configured policy. A missing
mutation route is tested as missing, not as a successful owner-profile access
test. Synthetic `image_kind` labels describe intended image tasks; rejection occurs
before image interpretation, so no interpretation result is claimed.

The frontend projection operation renders the original ScreenAwarenessPage with
React SSR. A `surface` label does not create a separate Workspace, Mini or Settings
execution. Actual shipped-page coverage and screenshots are recorded separately
in the seven browser development controls. These scope limitations remain in
each corresponding receipt and the independent report; matching a predicate
does not erase an untested dimension.

The strict synthesis-only expectation remains a failure: current logical TTS
activity includes preparation before playback. No measured first-audible signal
exists, and no acoustic timing metric is inferred from that logical field.
