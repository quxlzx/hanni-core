The first engineering cycle repairs request interpretation and completion bookkeeping in the original MCP controller. The frozen new-development metadata checks improve from 237/370 to 286/370, with 49 previously failing requests repaired and no formerly passing request regressed within that corpus. After the complete real development collection, a second narrow cycle adds clause/context, process-verification and unit-argument repairs; its stable checkpoint is 287/370 metadata passes and 200 relevant regression passes. The clean full suite passes 2,261 tests with two skips, and ten historical corpora have zero casewise regressions and three improvements. Independent development replay still exposes response limitations; the independent final run remains pending and Manager-owned. Metadata availability and unit tests do not prove real model reasoning, successful desktop effects or full requested-field completion.

## Reproduced faults and repairs

- A negative constraint could select the forbidden operation or suppress a valid observation. An archive listing with “never extract” was blocked; inspecting a PID with “do not terminate” was blocked. Planning text now retains positive requests, masks quoted argument instructions and removes syntactically bounded negative constraints. Literal argument text remains available to the original resolvers. A later positive clause survives a preceding prohibition, while a positive restricted mutation remains blocked.
- Educational, fictional and quotation-analysis requests could expose live observations or actions before no-tool interpretation. A RAM definition selected hardware tools, and analysis of a quoted Spotify command exposed launch/playback tools. Text-only intent is now identified before provider retrieval. The legacy router represents this with zero tools and `clarification` status; the actual fallback conversation, rather than that legacy status label, determines whether the owner receives an explanation or an unnecessary question.
- Broad object words could outrank a more specific local operation. Google Drive displaced a local encryption check; process identity displaced program uptime; an ordinary file read displaced Git history. Narrow operation/object precedence preserves the original source and does not grant authority.
- Unsplit requests containing independent observations could expose only one operation. The bounded menu now reserves explicit observations such as firewall plus Defender, repository status plus commit history, or free VRAM plus free storage.
- The original completion ledger treated the union of an unsplit menu as interchangeable evidence. One firewall receipt could therefore complete a request that also required Defender. Router `required_groups` now distinguish independent obligations. The original ledger retains the other obligation after a successful first receipt, and aliases remain alternatives when no independent group is declared. Failed or unverified evidence does not complete the missing obligation.

The independent Verifier reproduced eight reported development failures before changes and authored additional unseen development variations. On the first cycle freeze, all 16 exposed representative/variation menus meet their authored observation or zero-menu expectations. All three independent partial-receipt ledger reproductions retain the missing observation. A leading repository scope no longer creates a false file subtask.

The Manager's wider comparison reopened that initial freeze after 14 historical public-development regressions. The causes were generic named-process lookup overriding existing model-status semantics, an educational prefilter excluding first-person resource and assistant-permission questions, and comma splitting removing the symptom from its culprit request. Independent fresh wording reproduced the state and model-status faults before edits. The router now preserves state references and the existing general-slowdown contract, retains explicit named-process/executable lookup precedence, puts generic running-name lookup in the original anchored catalog rule after existing model-specific rules, and keeps a diagnostic statement attached to its comma-following request. No permission is inferred from those observations. The independent Verifier confirms 34/34 exposed context checks, including all 14 historical requests, fresh variants, explicit process resource targets and the additional original HANNI GPU-placement/Llama-status regressions. The completed wider comparison on the stable second checkpoint has zero casewise regressions across ten historical corpora.
