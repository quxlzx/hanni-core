## Scope and remaining limits

The scheduler uses a bounded static validated plan. Known independent local reads may run in parallel; imported/unknown resource operations serialize. Supervised mode automatically admits a narrow authorized local-read/checked-analysis scope. Sensitive steps need exact owner review. Background mode additionally requires prior workflow scope and original per-tool background permission. Model plans cannot approve themselves, change the actor or supply new execution authority.

Uncertain write acknowledgment never triggers automatic replay. Stateful/closure/default-bound definitions may invalidate consent after reconstruction; changed unfinished bindings require a new goal/plan. Scope renewal preserves completed verified work and the original duration deadline. Synchronous tools/model inference cannot be forcibly interrupted; withdrawal blocks further admissions and remains pending until the active call returns.

Analysis verification covers declared verified observations and deterministic value/count/sum/difference/ratio/percentage calculations. Saved bytes/hashes do not establish free-form causal conclusions or whole-goal semantics. Imported remote self-reported success remains UNVERIFIED without independent evidence. Unsupported benchmarking, screen understanding and provider/cluster execution stay blocked or untested rather than fabricated. Current scheduler leases are local, not distributed ownership.

Temporary/private workflow context remains distinct from permanent memory. Original memory consent applies; workflow data is not automatically promoted. Settled records have bounded retention; uncertain effects and live reviews are retained. Expired request tombstones prevent old UUID replay from recreating an action. Managed artifact cleanup refuses junctions/escapes and preserves a pending queue for locked paths. Missing/stale resource evidence, storage failures and clock rollback fail closed. Admission limits do not implement kernel CPU/GPU throttling or exact internal provider request accounting.

Future work should add independently evidenced provider outcomes, explicit audited effect reconciliation and cooperative cancellation before widening autonomy. Screen/benchmark/cluster features must enter original capability discovery, permission and verification contracts. Stronger planning should be evaluated on a newly sealed cohort rather than tuning to the now-scored final cases. Repeated quiet paired timers should separate retrieval, handler/verification, SQLite commits and recovery-to-safe-state from owner-resumed completion.
