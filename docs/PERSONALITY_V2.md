# Personality V2

HANNI's configured `hanni` personality now uses a shorter, grounded style prompt. It asks for the result first, casual warmth without service phrases, clear action-status wording, and explicit separation of available Calendar time from the duration the owner requested. The base identity and safety instructions remain in force. HANNI does not impersonate a person or celebrity.

`hanni eval personality-v2 --limit 50` compares neutral and V2 replies on the same 50 synthetic-evidence cases. The cases sample diagnostics, direct system questions, Calendar, apps/media, files, model state, mixed requests, conversation, and safety from the development tool corpus. This is a style and grounding development audit, not a blind task-success benchmark; it does not execute any MCP capability.

The clean [paired report](../evals/personality/results/final_generalization_personality_v2_ab_clean.json) has 50 pairs. Neutral and V2 both matched all required lexical claims in 93.18% of the 44 claim-bearing cases. V2 had zero observed unsupported-pattern or identity hits, versus zero for neutral, and zero customer-service phrase cases versus four for neutral. Mean response length fell from 18.54 to 16.24 words. Mean latency was 1,076 ms neutral and 1,099 ms V2. Manual review of the Calendar time-window case confirmed that V2 reported 165 minutes available and said a two-hour game fits; the first candidate had mistakenly said exactly two hours were available. A separate Calendar mock inconsistency was corrected before this clean run.

These lexical proxies do not prove warmth, naturalness, or complete factual correctness. The paired responses are saved for review. The production `hanni eval llm-tools` benchmark remains the check for routed tool use, final conclusions, and safety. The combined production base/personality/tool-policy prompt is 603 words versus 611 before V2; no safety rule was removed to save tokens. The live tool benchmark records actual prompt tokens including routed tool schemas.
